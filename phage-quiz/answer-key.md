## Round 11 — RAPID FIRE
*+5 correct / 0 wrong · 60 s*

### Lytic Legends

1. Enzyme that degrades the peptidoglycan at the end of the lytic cycle  →  **Endolysin (lysozyme)**
2. Term for a phage genome integrated in the host chromosome  →  **Prophage**
3. UV light or mitomycin C triggers this event in a lysogen  →  **Prophage induction**
4. The protein shell that encloses the phage genome  →  **Capsid**
5. The myovirus structure that contracts during infection  →  **Tail sheath**
6. Number of progeny released per infected cell  →  **Burst size**
7. Filamentous phage widely used for phage display  →  **M13 (f1/fd)**
8. Ions added to media because many phages need them for adsorption  →  **Divalent cations (Ca2+ / Mg2+)**

### Biofilm Breakers

1. Matrix component degraded by phage depolymerases in a biofilm  →  **Exopolysaccharide (EPS / capsule)**
2. Phage-mediated transfer of bacterial DNA between cells  →  **Transduction**
3. Microscopy that images phages in a near-native frozen-hydrated state  →  **Cryo-EM (cryo-TEM)**
4. The phage life cycle that ends in host lysis  →  **Lytic cycle**
5. Extrachromosomal bacterial element that often carries AMR genes  →  **Plasmid**
6. A phage particle that lacks its genome  →  **Empty capsid (ghost)**
7. The workbench host bacterium of the T-phages  →  **Escherichia coli**
8. Ecological model: phages lyse the most abundant host (3 words, “kill the …”)  →  **Kill-the-winner**

### Phage Pharmers

1. US regulatory route for compassionate phage use (3 letters + IND)  →  **eIND (emergency/expanded-access IND)**
2. Full name of PEG, used with NaCl to precipitate phages  →  **Polyethylene glycol**
